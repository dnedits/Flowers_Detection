# Определение растений по фотографии — YOLOv8 + FastAPI 🌹


---

## Краткое описание

**Сервис определения растений по фотографии** — это комплексное приложение для **автоматической идентификации растений** на основе **YOLOv8 (Ultralytics)** и **FastAPI**.

Пользователь может загрузить **изображение растения** через веб-интерфейс или отправить фото в **Telegram-бота**. Система возвращает:
- изображение с выделенным обнаруженным растением (bounding box);
- название растения;
- процент уверенности модели.
- текстовое дублирование информации.

---

## Основные возможности

### 🔍 Определение растений по фото
- Загрузка изображений в форматах JPG, PNG
- Высокоточное обнаружение и классификация растений
- Визуализация результата с рамкой и подписью
- Отображение уверенности модели в процентах

### 🌐 Веб-интерфейс
- Интуитивно понятная загрузка файлов
- Адаптивный дизайн (работает на ПК, планшетах, смартфонах)
- Мгновенный вывод результата
- Кнопка перехода в Telegram-бота

### 🤖 Telegram-бот
- Приём фотографий через мессенджер
- Быстрая обработка и отправка результата обратно в чат
- Поддержка команд `/start`, `/help`
- Удобный интерфейс с кнопками

### 📊 Результаты распознавания
- Название растения (на русском/английском)
- Процент уверенности
- Визуальная разметка на исходном изображении
